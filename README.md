# study-hubs

Interactive study hubs for UAB dental school coursework, served via GitHub Pages
at [smcmurry6-source.github.io/study-hubs](https://smcmurry6-source.github.io/study-hubs/).

**Editing this repo from a Claude session or Project? Read [`DEPLOY_NOTES.md`](./DEPLOY_NOTES.md) first** —
it covers the shared `widget/` infrastructure, the Supabase backend, and the
merge-before-you-push rule that keeps multiple Claude Projects from silently
overwriting each other's work.
