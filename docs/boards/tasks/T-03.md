## Perio-specific rules

- **Classification wording:** use the 2017 AAP/EFP World Workshop terms exactly as the facts give them (stage, extent,
  grade; "gingival health on a reduced periodontium"). Older terms (chronic/aggressive periodontitis, Miller recession
  classes) appear only as "older term" with the current one next to it.
- **Charts as text:** cases give probing depths, CAL, BOP and radiographic bone loss in the box as text ("Tooth 3
  mesiobuccal: PD 6 mm, CAL 5 mm, BOP"). Write "tooth 3", never "#3" (the lint fails it anywhere in an item or box).
  Code-drawn chart figures come later (`items-perio-b`); don't add `img` keys.
- Staging and grading cases must contain every number the stage and grade need (interdental CAL at the worst site,
  bone loss %, tooth loss due to periodontitis, complexity factors, smoking and A1C), so an item has exactly one right
  stage and grade.
