## Outcome (2026-11-24)

Done in one PR into `claude/boards-hub`. What differs from the brief, and why:

- **`UNITS` lists pharm and medcx** (both still `preview`, so only their titles show, as coming): the engine reads its first
  lecture to draw Home and Notes, so a hub with no lecture shows "Something went wrong" there.
- **`config.GROUPS`** holds the three components with their units by home CC (BUILD_SPEC 3.1). anat, physio, micro and
  gpath have no home CC; the build fails on a published unit in no group, so their group is decided before one ships.
- **`tools/hub-next/build.mjs` exports `buildFrom()`** (the same build on content in memory, for `--check`) and lets a hub
  whose lectures are none of them taught have no questions. Every other hub builds as before.
- **`facts.json`** is `{ facts: { <id>: [<source ids>] }, sources: { <id>: { name, org, url, date } } }`: a source is
  written once, not once per fact (36 KB instead of 174 KB for the drafts preview).
- **Lectures** carry `label` ("U15"), `who` ("INBDE and ADEX") and `from`, which the engine prints, besides the plan's
  fields. `study.json` is empty lists; `core.json` has `srcLabel` ("Board fact") and a mock of every published unit's
  questions (up to 30 each) at 63 seconds a question, with `mock.blocks` for T-14.
- **The smoke test** picks the first hub with questions for its one-hub checks (`firstHub`), so a hub with none published
  is walked but never picked; its export and "Ask Timmy on a question" checks note instead of failing when a hub has none.
